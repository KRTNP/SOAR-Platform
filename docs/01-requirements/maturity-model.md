# Maturity model

| Level | Capability | เกณฑ์ผ่าน |
|---|---|---|
| 0 Manual | checklist และ handoff | มี owner และ scope ชัด |
| 1 Assistive | enrichment, ticket, notification | analyst เห็น input/output ครบ |
| 2 Repeatable | dedup, reusable playbook, audit | replay และ versioning ทำได้ |
| 3 Governed | approval, policy-as-code, rollback | high-impact action มี gate |
| 4 Measured | SLO, outcome metrics, regression | วัดคุณภาพและปรับปรุงจากผลจริง |
| 5 Adaptive | recommendation/AI assist | human validates, evidence-backed, bounded tools |

MVP ตั้งเป้า Level 2 และบางส่วนของ Level 3; ไม่ตั้งเป้า autonomous Level 5 เป็นเงื่อนไขเปิดใช้งานระบบ
