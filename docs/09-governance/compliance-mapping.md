# Compliance mapping

| Design control | NIST CSF 2.0 / IR relation | Evidence |
|---|---|---|
| asset/user scope | Identify/Govern | inventory และ scope record |
| telemetry and detection | Detect | source/rule/query reference |
| response plan and approval | Respond | playbook/execution/approval |
| evidence and recovery | Respond/Recover | hash, custody, recovery task |
| metrics and lessons learned | Improve | KPI, tabletop, revision |
| access and secrets | Govern/Protect | RBAC, credential audit |
| vulnerability workflow | Identify/Respond | CVE assessment/mitigation verification |

ตารางนี้เป็น design mapping ไม่ใช่การรับรอง compliance; ต้องเทียบกับข้อกำหนดขององค์กร/สัญญา/กฎหมายจริงก่อนใช้งาน
